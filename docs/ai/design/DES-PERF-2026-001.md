## Initial design choices
- Start with a single Spring Boot service skeleton under `com.companyrule.performance`.
- Use in-memory storage first to keep the first compile/test target small.
- Add SQL migration files now so schema intent is visible even before runtime DB integration is wired.
- Treat organization lookup as a stubbed adapter boundary for the first slice.

## Data intent
- `perf_cycle`
- `perf_template`
- `perf_plan`
- `perf_review_record`

## Security posture
- Keep role/ownership checks as explicit next-step work.
- Keep release, rollback, and high-risk edits manually reviewed.
